# 公众号交稿通用检查清单（全账号适用）

每次交付前逐项自检，任一项不通过不得交稿。

---

## 0. 前置检查

- [ ] 是否已锁定账号 + style（回执用户：`已锁定账号：{account}｜风格：{style}`）
- [ ] 是否已打开并snapshot所有用户提供的素材链接
- [ ] 是否已主动搜索至少3-5篇补充素材（不仅依赖单源）

---

## 1. 字数

- [ ] 正文纯汉字数在 600-900 字
- [ ] 使用 `grep -o '[一-龥]' | wc -l` 严格统计，不靠估算

---

## 2. 标题

- [ ] 长度严格控制在 style 定义的范围内（style-a: 16-24字 / style-c: 12-20字）
- [ ] 先抓人，再给信息点，不搞平淡陈述
- [ ] 没有AI化词语（瞬间归零、立马等）

---

## 3. 摘要

- [ ] 长度严格控制在 style 定义的范围
- [ ] 不重复标题，补一层判断或悬念
- [ ] 口语化、有钩子

---

## 4. 首段

- [ ] 开头先说清"这是什么"，外行人能一眼看懂，再接叙事
- [ ] 3句内必须拉人进来（场景/矛盾/数字/问题切入）
- [ ] 不是新闻导语式开门见山
- [ ] 没有"近日/随着/在当前背景下"等模板

---

## 5. 正文结构

- [ ] 使用───分隔大块（全文4-5大块）
- [ ] 每块有小标题，口语化「」胶囊式格式，像人口语不像目录——**禁用"1. XXX""2. XXX"等编号目录式标题，禁用"一/事件背景"等模板标签**
- [ ] 陈述句段尾不加句号
- [ ] 没有项目符号列表
- [ ] 没有高密度AI对照句型（不是……而是……等）
- [ ] 没有书面汇报腔

---

## 6. 语言

- [ ] 全文无关联词语/过渡句（这才是、真正要命的是、值得注意的是等——对照banned-phrases.md）
- [ ] 像真人在聊天，不是在写文章（读出声检查）
- [ ] 复杂概念已翻译成人话类比
- [ ] 至少有一句可截图传播的金句
- [ ] 口语化、有活人味，但不油腻不低俗

---

## 7. 结尾

- [ ] 有收束判断，不灌鸡汤
- [ ] 有评论区提问钩子（"你怎么看" / "你觉得……"），**不说"下篇聊/下篇拆"等预告口吻**
- [ ] 有引流模块（按style约定：style-a用群引流模板+官网链接，style-c用评论互动）

---

## 8. 配图

- [ ] 封面图与首节配图是两张不同的图片（非同一文件）
- [ ] 所有小标题节上方均有一张独立配图，无遗漏
- [ ] 图片中无来源媒体logo/水印/品牌标识（如深潮TechFlow、PANews等）
- [ ] 封面图 prompt 不默认输出，仅用户明确要求时才自动添加
- [ ] 配图走「中间地带」：不太写实（不用纯产品图/芯片图），不太抽象（读者看不懂跟内容的关系）。一眼能看出跟哪段内容相关，同时有画面张力
- [ ] 每张配图自问：撤掉它会少get到什么？答不出 图选偏了必须重选

---

## 9. 排版（纯文本版）

- [ ] 高频分段，扫读友好
- [ ] 重点词（2-4个）已加粗
- [ ] 重点句（2-3句）已加粗
- [ ] 小标题使用`「」`胶囊式格式并加粗
- [ ] 只有大块之间（───）换行两次，段落之间只换行一次
- [ ] 陈述句段尾不加句号

---

## 10. 排版（HTML版）- 仅在输出HTML时检查

- [ ] 每句独立换行（每句话单独一行）
- [ ] 段落间距 `margin-bottom: 28px`（避免拥挤），行高 `line-height: 1.8`
- [ ] 句末不写句号，感叹号和问号保留
- [ ] 小标题格式：加粗+深红底白色字 `inline-block; background:#a93226; color:#fff; font-weight:bold; font-size:17px; padding:4px 20px; border-radius:20px`
- [ ] 标题段前距、段后距强制为0
- [ ] 正文颜色 #3f3f3f，字号 17px

---

## 11. 关键数据标红检查（HTML版强制）

- [ ] 重要关键词、核心数据（数字、产品名、关键金额）、核心判断句已用 `<span class="hl">关键词</span>` 标红加粗
- [ ] 标红数量在 10-15 处（每段最多1-2处）
- [ ] 全文至少 50% 的关键数字/产品名已标红，无遗漏明显数据
- [ ] CSS 中已定义 `.hl { color: #a93226; font-weight: bold; }`（无此定义则 `.hl` 不生效）
- [ ] 标红分布均匀，不是只有开头有、后面全无

## 12. 素材痕迹检查

- [ ] 逐句扫描正文，无"原文中提到的/原贴里说/素材显示/我看到有人说/这两篇内容/某站报道说/有媒体称/据说"等素材处理痕迹
- [ ] 引用来源直接写主体（ZachXBT说、吴恩达说、据《纽时》报道），不写模糊信源
- [ ] 所有信息已用自己的语言重新表达，没有直接复制粘贴

---

## 12. 节奏检查（进阶）

- [ ] 通读一遍，有没有哪里像"写文章"不像"在聊天"？改掉
- [ ] 金句够锐吗？有人会截图传播吗？不够就打磨
- [ ] 小标题读着有画面感吗？太普通的换掉

---

## 13. 政治敏感检查（涉中美/地缘题材强制）

- [ ] 标题是否以"中国被拒/被排除"为主线？→ 是：改写
- [ ] 开篇前3句是否构成"中国丢脸/挨批"叙事？→ 是：改写
- [ ] 是否有外媒直接对中国做负面定性的引述？→ 是：删除
- [ ] 源方对中国贴标签的原话是否已中性化改写（"对抗性国家"→"严格限制名单"）
- [ ] 结尾是否落在被动/悲观方向？→ 改为主动追赶或国产替代
- [ ] 全文读毕，情绪是"中国被欺负了"还是"赛道在加速"？→ 必须是后者
- [ ] 详见 `references/political-sensitivity.md`

---

## 14. 事实核查（强制 — 交付前最后一道门禁）

*以下核查在文章写完、自检通过后执行，不通过不得交付。*

### 事实提取（逐句扫，列出所有可验证的声称）

- [ ] 文中所有数字（金额/百分比/分数/排名/日期/时长）是否已列出
- [ ] 文中所有产品名/平台名是否已确认具体指代（同名异物风险）
- [ ] 文中所有事件声称是否有来源可查
- [ ] 文中所有因果声称/对比声称是否有事实依据
- [ ] 文中所有引用/转述是否可追溯到原文

### 核实执行

- [ ] 每个核心数字已找到官方来源或 ≥2 个独立权威来源交叉验证
- [ ] 产品/平台定价已上官网核实（不是抄二手数据）
- [ ] 排行榜/分数已上最新榜单确认（不是引用过时数据）
- [ ] 所有社媒数据已标记为"引子"，未当作数据来源使用
- [ ] Token/代币相关数据已确认平台定价体系（DS4的token ≠ AccioWork的token）

### 交付门禁

- [ ] 无 ❌ 标记的事实（全部可核实或已核实）
- [ ] 有 ⚠️ 标记的事实已在回执中标注说明
- [ ] 核心数字全部 ✅（金额、排名、分数任何一项如果是 ❌ 则禁止交付）
- [ ] 核查结果已附在交付回执中（简短版即可）
