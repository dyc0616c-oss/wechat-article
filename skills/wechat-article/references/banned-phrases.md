# 禁用词句与降AI味规则（v1）

## 尽量避免
- 赋能、抓手、闭环、矩阵化、全方位
- 综上所述、毋庸置疑、不难发现
- 过于模板化转折：首先/其次/最后（连续堆叠）

## 禁止行为
- 编造数据来源
- 无依据给确定性收益结论
- 标题与正文内容不一致
- 使用无序列表或有序列表排版公众号正文

## 替代建议
- 用具体场景替代抽象概念
- 用“如果A/如果B”替代绝对判断
- 用短句和动词替代名词化表达

## 账号专属红线（v2）
- 避免明确指控“诈骗/违法”除非有公开监管结论或可核实证据
- 涉及金额、涨跌幅、处罚数字时，尽量给来源描述（如“监管通报/平台公告”）
- 可有态度，但避免人身攻击与侮辱性措辞

## 通用禁止的关联词语/过渡句（v3 — 全账号适用）
以下表达在**任何风格**的文章正文中都不允许出现：
- 这才是这波最值得盯的地方 / 这才是最值得关注的点
- 真正要命的是 / 真正厉害的是 / 真正的杀招是
- 但真正让……不是……而是……（以及任何对照转折句型）
- 这件事最……的是 / 这波最……的地方
- 这意味着什么 / 这说明什么
- 值得注意的是 / 不容忽视的是
- 在某种意义上 / 从某种意义上说

**替代方案：** 直接陈述事实+接判断，不要用过渡句"带话"。感觉需要推进行文时，用小标题或空行───切换，不靠关联词。

## 通用禁用副词（v4 — 全账号适用）
以下副词在正文中**完全禁用**，直接删掉或换具体描述：

- 迅速、立即、瞬间、立马、显著、大幅、快速
- 完美地、出色地、成功地、有效地、极大地
- 实际上、事实上、本质上、根本上、实质上
- 越来越、进一步、更好地

**替代策略：**
- 具体数字替代程度副词：不说"大幅增长"，说"翻了三倍"
- 具体动作替代评价词：不说"出色完成"，说"三天搞定别人两周的活"
- 场景替代判断：不说"他很厉害"，说"他一个人写了三个人的代码还在打游戏"

## 通用禁用句式（v4 — 全账号适用）
以下句式及近似变体在正文中完全禁用：

- 这是一个值得深思的问题
- 机遇与风险并存
- 本文将从……展开
- 从某种意义上说
- 这充分说明了
- 其核心在于
- 本质上而言
- 投资者应保持理性

## 素材痕迹禁用词（v5 — 全账号适用）

正文**完全禁止**暴露后台素材处理痕迹。以下表达及近似变体一律禁用：

- 原文中提到的 / 原文显示 / 原文指出
- 原贴里说 / 原素材提到 / 素材显示
- 这条推文里讲到 / 我看到有人说
- 某篇文章标题 / 外链标题 / 搜索结果标题
- 某站报道说 / 有媒体称 / 据说
- 经验贴里提到 / 作者说 / 这两篇内容

**正确做法：** 直接写来源主体+事实。不写"原文提到Bitget"改写成"ZachXBT在X上直接点名Bitget"；不写"素材显示LAB暴涨500%"改写成"LAB在5月初暴涨500%后暴跌84%"。

**交稿前自检：** 逐句扫描正文，但凡有一句话需要先脑补一个「某篇文章说」才能成立，就是素材痕迹，必须改。
