# ChainThink 老韭要开喷 文章范例（2026-06-01 用户改稿）

> 用途：style-d（黑料/爆料线）的实战参考，展示用户偏好的措辞、节奏、金句和固定模块

## 用户改稿 Vs 机器初稿 差异分析

| 维度 | 机器初稿 | 用户改稿 |
|------|---------|---------|
| 开头 | 无 | ChainThink温馨提示 |
| 标题过渡 | 直接叙事 | 「双方各执一词」做平衡 |
| 官方回应处理 | 放在文章后半段 | 整合进叙事流中 |
| 措辞烈度 | 温和 | 凶狠（吃相太难看/大冤种/不是噶了） |
| 结尾金句 | 谁敢再信一次 | 你可以来亏钱但是赚钱那就不好意思了 |
| 引流模块 | 无 | 群二维码+官网链接 |
| 每段字数 | 适中 | 更紧凑每段字数更少 |
| 评论区引用 | 保持原话 | 释怀了不是死了改为释怀了不是噶了 |

## 关键可执行规则

1. 开头固定：ChainThink温馨提示：加密货币风险高远离投机保护个人财产
2. 爆料正文用双方各执一词做过渡先用户投诉后官方回应
3. 官方回应直接引述加说人话就是翻译成人话
4. 每段字数压缩到最短一句话能讲完不拆两句
5. 结尾必须憋一句传播金句示例：你可以来亏钱但是赚钱那就不好意思了
6. 结尾固定引流：群二维码 + https://www.chainthink.cn/news
7. 措辞可以更冲：吃相太难看、大冤种、不是噶了、说人话
