# Web3 风格模板（基于链智库写作体系）

> 这是基于实战验证的 Web3 公众号写作风格。按你的账号调性修改各字段即可。

## core_goals

- 开头就抓人，3句内让读者知道「发生了什么」
- 每篇必有震撼数字（金额要大、对比要狠）
- 把所有 Web3/加密黑话翻译成人话（GMV→卖了多少钱）
- 每篇至少1句可截图传播的金句
- 短句推进，大量单句成段，禁止大段堆砌
- 判断落在具体事件+数字上，不讲空话

## 文章框架：五段推进

```
① 引钩（1-3句）         → 场景代入 / 矛盾对比 / 事件直切
② 事件（摆事实）        → 数字暴力 + 谁发生了什么
③ 分析（为什么会这样）  → 拆解推动力/利益方/底层逻辑
④ 格局（这意味着什么）  → 对行业/普通人/投资者的影响
⑤ 收束（金句/反问）     → 不画句号，留余味
```

## 六种钩子手法（每篇必用2-3种）

### 1. 场景钩子
第二人称把读者拉进故事，3句内产生代入感。

### 2. 数字震撼钩
绝对数字直接砸脸，不铺垫。

### 3. 矛盾对比钩
两个对立事实硬拼，读者自动产生「为什么」。

### 4. 横向类比钩
用读者熟悉的框架框住陌生事件。

### 5. 行文反问钩
先设问，立刻自答，节奏极快。

### 6. 开放式反问（结尾专用）
结尾不画句号，抛新问题制造追读。

## title

- length: 15-22字
- style: 矛盾型陈述 / 利益冲突型问句
- 必有数字或强烈冲突感
- 先抓人，再给信息点

## digest

- length: 10-15字
- 矛盾并列型 / 信息差型
- 不重复标题，补「为什么」
- 一句话

## opening

- 用一句普通人能看懂的话把事件/对象讲清楚
- 快速交代「这是什么」，再讲叙事和情绪
- 不做大段背景铺垫

## body

- paragraph_count: 4-6个逻辑段
- sentence_mode: 短句扫读，大量单句成段
- 每段只讲一个核心点，节与节之间有逻辑递进
- 从热闹→门道→判断的推进逻辑

## 小标题风格

- 口语化带路句，2-4个
- 不是正式目录，是引导读者往下看的钩子
- 格式：用「」圈起

## 翻译规则（强制）

所有技术术语必须配一句人话类比或白话解释：
- 首次出现专业术语时，用括号/紧跟一句白话解释
- 公式：技术概念 + 「打个通俗比方」 + 生活化类比
- 示例：「GPU是发动机，HBM就是油箱和高速输油管」

## 人物命名规则

- 说人名不说公司名（「奥特曼」不说「OpenAI公司」）
- 把机构还原成人，方便读者情绪代入
- 英文名首次出现时括号备注中文译名

## language

- 口语化、有攻击性、像朋友吐槽
- 允许调侃、反问、轻吐槽
- 数字要大：万亿/亿/万，对比要狠
- 用「」圈重点词增强扫读感

## ending

- 金句收束 + 开放式反问
- 无固定引流模块
- 禁止「下篇聊/下篇预告」等编辑预告口吻
- 收束段有一句可截图传播的短判断（20字内）

## banned_patterns

- 禁用「近日/随着/在当今」模板开头
- 禁用「首先其次最后」流程化
- 禁用抽象大道理
- 禁用 AI 腔总结段
- 正文禁止出现后台素材痕迹（「我去查了/推特上说」）
