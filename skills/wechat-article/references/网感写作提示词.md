# 网感写作提示词（2026-05-13 搜自网络）

从 Google、Metaverse Post、Moz 等来源整理的网感写作 prompt 模板和检查规则，专为 style-c（Ai吹哨兵）等需要活人味的公众号风格优化。

---

## 1. 全网最佳综合提示模板

```
【写作任务】写一篇关于[主题]的公众号文章
【网感写作规则】
1. 主动语态：用"我""咱们"，把读者拉进故事
2. 短句短段：一段不超过4行
3. 口语对话：多用"真的""绝了""这就很离谱"
4. 情绪价值：开篇直击痛点，结尾给出吐槽性总结
5. 禁止废话：禁止说教，直接分享故事、槽点、具体细节
```

## 2. 人设先行法

> 请你扮演一位百万粉丝的公众号博主，说话风格[犀利/幽默/接地气]，擅长用口语化表达、网络热梗和紧凑叙事。禁止书面化、禁止AI公文体。

## 3. 网感化重写指令

> 请按以下要求改写：
> 1. **语气**：自然、口语化，像在和朋友聊八卦
> 2. **结构**：多用短句。开头必须极具吸引力（悬念/情绪）
> 3. **网感**：恰当插入热梗，适当调侃，避免说教
> 4. **删除**：移除"综上所述、然而、此外、致力于、优化"等机械过渡词
> 5. **添加**：增加具体的场景细节和心理活动

## 4. 具体化策略（拒绝空谈）

> 不要说"产品效果很好"，要说"熬夜用了它，第二天同事以为我打了玻尿酸"
> 请用具体的、视觉化的场景描写来替代抽象概念。

## 5. 模拟人类思维跳跃

> 请故意打乱逻辑结构，在段落中加入看似"离题"但有趣的联想，或突如其来的吐槽，让文章更像人类思维的跳跃，而不是AI的线性输出。

## 6. 网感自检六问（交稿前问自己）

1. 第一句话扔出去够不够劲？还是像"今天我们来聊聊……"？
2. 这段读起来像一个人在说话，还是像模型在给你做作业？
3. 有没有一句可以截图传播的金句？
4. 有没有"然而/此外/值得注意的是"这类AI过渡词没删干净？
5. 每篇文章结尾落地在了一个具体的提问/判断，而不是飘在半空？
6. 有没有用具体场景替代抽象概念？（别说"提升效率"，说"半小时干完一天的活"）

## 7. 高频禁词清单（跨平台验证）

| 禁词/词族 | 替代 |
|-----------|------|
| 然而、因此、此外 | 直接省略或用短句自然推进 |
| 综上所述 | 删掉 |
| 致力于 | 说具体动作 |
| 优化 | 说具体改了什么 |
| transform、leverage、game-changing | 说人话 |
| 真正值得注意的是 | 直接说事 |
| 在……背景下 | 直接说具体事件 |
