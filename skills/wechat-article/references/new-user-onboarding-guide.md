## 一、系统能做哪些事

| 功能 | 说明 |
|:----|:-----|
| 风格学习 | 给5篇历史文章→自动生成你的专属 style 文件 |
| 单篇写作 | 给素材（X链接/文章链接/关键词）→ 出完整公众号文章 |
| 改写润色 | 给已有文章 → 按你的风格重写 |
| 降AI处理 | 检测→降AI→过朱雀 |

| 自动归档 | HTML 文件自动存到桌面指定目录 |

## 二、快速开始：定制你的风格

**你只需做一件事：给系统 5 篇你写过的公众号文章链接。**

### 第一步：准备样本

从你的公众号历史文章里，挑 **5-10 篇**，**要覆盖多样性**：
- 不同题材（热点、教程、观点、盘点各来1篇）
- 你认为写得好的（代表你想要的水平）
- 最好是近3个月的（风格稳定了）

把链接发给 Hermes，说一句：

> 「帮我学一下我的公众号风格，这是5篇文章链接：[链接1][链接2]…… 公众号名叫「XX」，定位是XX」

### 第二步：系统分析什么

Hermes 会从 **10个维度** 分析你的文章：

| 维度 | 看什么 |
|:----|:------|
| 标题 | 多长？悬念型/观点型/反差型？ |
| 摘要 | 信息差型还是钩子型？ |
| 首段 | 情绪切入还是背景切入？会不会有模板化开头？ |
| 正文结构 | 段落数？短段推进还是长段论述？ |
| 语言风格 | 口语化程度？犀利还是稳健？ |
| 叙事与判断 | 讲故事多还是讲道理多？ |
| 排版 | 小标题？重点句高亮？ |
| 结尾 | 怎么收束？有没有引流钩子？ |
| 图片策略 | 配图风格？图文位置？ |
| 禁用模式 | 什么写法绝对不能出现？ |

### 第三步：生成 style 文件

分析完，系统生成一个 **`style-你的号.md`**，里面是可直接执行的规则：

```yaml
# 你拿到的东西长这样
title:
  length: 12-20字
  style: 悬念/观点

body:
  paragraph_count: 4-6段
  sentence_mode: 每段1-2句

ending:
  hook: 评论区互动提问
  qr: 底部放二维码
```

系统还会告诉你：
- 🟢 **必须学的点**：你写得最好的特征
- 🟡 **建议学的点**：进一步提升的空间
- 🔴 **不要学偏的点**：你以前的某些习惯其实可以优化

> **整个过程大概 2-3 分钟**，你在对话框里等结果就行。

## 三、日常写一篇文章

**流程只有 4 步，30 分钟内完成：**

### Step 1：给素材

发一条消息给 Hermes，比如：

> 「写一篇公众号，用 Ai吹哨兵 的风格。素材是这条X链接：https://x.com/xxx/status/xxx」

可选附加信息：
- 目标读者是谁
- 这篇要涨粉 / 品牌表达 / 观点输出
- 预计字数

### Step 2：系统自动工作

系统会自动完成：

| 步骤 | 具体做什么 |
|:----|:----------|
| ① 锁定账号 | 读 account-style-map，确定用哪个 style |
| ② 读取素材 | 从X链接/api/网页提取全文 |
| ③ 搜索补充 | 搜3-5篇相关报道验证+补视角 |
| ④ 配图 | 从原文/X推文/免费图库下载配图 |
| ⑤ 写稿 | 按 style 规则写标题、摘要、正文 |
| ⑥ 事实核查 | 逐句验证文中所有数字和声称 |
| ⑦ 排版 | 套 HTML 模板，存到桌面 |
| ⑧ 交付 | 把 HTML 路径发回给你 |

### Step 3：降AI（可选，默认不自动执行）

写完稿子系统会问你要不要降AI。你有两个选择：

| 方案 | 说明 | 适合谁 |
|:----|:-----|:------|
| **付费工具** | 用市面上的降AI工具处理1-2轮 | 有预算，追求最高质量 |
| **手动降AI** | 系统做轻量语言替换（换高频词、调语气） | 没工具，或者要求自己动手 |

### Step 4：去公众号编辑器贴进去发

系统给你的 HTML 文件路径是：
`~/Desktop/公众号文稿/月.日/公众号名/标题.html`

在编辑器里：把 HTML 内容粘贴到公众号编辑器 → 过一遍排版 → 发。

## 四、如果你有多个公众号

**操作流程：**

1. 每个号走一次「风格学习」（给5篇文章→生成对应 style）
2. 系统会在 `account-style-map.json` 里维护所有账号的映射
3. 写稿时只要说「用哪个号」，系统自动切换风格

**并行生产**：如果你想同一主题发 5 个号，说一句：

> 「按 chainthink + 老韭要开喷 + Ai吹哨兵 + Ai掘金仔 + 智AI研究社 这5个号的风格，各写一篇关于XX的文章」

系统会先写一份中性母稿，再按每个号的风格逐一改写。

## 五、关键规则（一学就会）

### 写作铁律

| 规则 | 一句话 | 为什么重要 |
|:----|:------|:----------|
| **不编造** | 找不到真实案例就删段，不虚构 | 用户会查，一查就翻车 |
| **不凭记忆写** | 每个事实点回到原文核实 | 记忆会偏差，出过事 |
| **自己是源头** | 文章要像账号自己的原创，不是回应别人 | 「我看到有人说」=用户会骂 |
| **每段1-2句** | 不把3句塞进一段 | 手机上扫读舒服 |
| **给普通人看** | 不说GMV说「多卖了几成」 | 读者看不懂术语就不看了 |

### 标题怎么起

- **12-20字**
- 必须有信息增量（数字/人名/冲突/反常识）
- 读起来不像新闻标题
- 系统默认出3条候选：悬念型/利益型/观点型各1条

### 段落节奏

- 每段1-2句（2句饱满、1句不碎）
- 陈述句尾去掉句号
- 关键数据标红
- 小标题用「」胶囊式（不是编号）

### 配图

- 每节一张图，放在小标题正上方
- 从源素材/免费图库下载到本地 `图片/` 文件夹
- 不使用AI生图
- 不可有水印/媒体Logo

### 结尾

- 必有评论区互动钩子：「你怎么看，……？」
- 不可用「下篇聊/下篇预告」这类编辑预告
- 必须有一句可截图传播的金句（20字内）

## 六、系统工作原理（给好奇心强的用户）

这套系统的核心是 **Hermes Agent** + **两个技能文件**：

```
wechat-article（主技能）
├── SKILL.md            ← 主控规则（37+节）
├── references/
│   ├── account-style-map.json  ← 账号→style 映射
│   ├── style-*.md             ← 每个公众号的风格卡
│   ├── article.html           ← HTML模板骨架
│   └── 40+个参考文件          ← 各类专项规则
└── scripts/             ← 自动化脚本

anti-ai（降AI技能）
└── 8步降AI流程 + 词库替换表
```

你只需要会用。不需要懂这些文件结构——Hermes 会自动加载它们。

## 七、常见问题

### Q：我没写过公众号，第一次用，能直接写吗？
可以。系统有一个默认的中性风格，写普通的公众号文章没问题。但建议你先写几篇适应一下，再让系统学你的风格。

### Q：我上个月用过一个版本，现在版本有变化吗？
这套系统是 Crayon 从 2026年3月到6月持续迭代的实战成果，所有规则都是被用户骂过、改过、验证过的。如果后续你发现系统的某个行为不对，可以跟我说，我来更新规则。

### Q：系统写的文章我可以直接发吗？
建议先过一遍：标题够不够炸？有没有事实错误？配图对不对？排版在自己手机上扫一遍。系统不是完美的，但它出的稿子质量比95%的AI写作工具高。

### Q：怎么把系统接入微信后台自动发草稿？
需要微信开发者平台的 AppID + AppSecret，设置IP白名单。详见 `references/wechat-setup-guide.md`，按步骤操作即可。

### Q：我想改我的 style 文件，可以吗？
直接说「修改我的 style，把结尾改成……」，系统收到后会用 `skill_manage` 更新 style 文件。不需要你手动编辑文件。

### Q：我觉得某次写的不像我的风格？
把「不像」的那篇发回来，说说哪不像，系统会调整 style 规则并更新文件。多调整几次会越来越准。
