# AI城市宣传片制作工作流（2026-05-26 实战案例）

**来源：** X用户 @btcup99 分享的完整工作流（原文：x.com/i/article/2058796622662823936）
**适用账号：** style-money（Ai掘金仔）— AI赚钱路径拆解
**核心洞察：** 不是让AI直接生成长视频，而是拆成几个稳定步骤

## 完整工作流（五步）

### 第一步：ChatGPT 做前期策划
输出三个核心内容：
1. 整体脚本（60秒）
2. 六段分镜文字框架
3. 每段视频生成提示词

**关键指令：**
> 我要做一个家乡/城市的高端文旅宣传视频，我需要你帮我设计并生成用于分镜/分解图海报的提示词，核心内容要满足专业级城市宣传片所覆盖的所有方面，我的城市是《这里换成你想做的城市》。最终将提示词分成6段给我，每段设置4个分镜头，但需保持主题统一、镜头连贯、节奏完整

### 第二步：GPT Image 生成分镜参考图
- 每段生成4张分镜图（6段 × 4张 = 24张）
- 这些图不是最终视频，是视觉参考
- 作用：保证城市风格统一、镜头氛围统一、画面元素更稳定

**重点：** 确认分镜图满意后，让GPT Image输出每段视频的生成提示词

### 第三步：豆包 / Seedance 逐段生成视频
- 每段生成10秒视频
- 参考图+提示词一起输入
- 每段单独生成的好处：镜头可控、出错只重做某一段

**六段典型编排：**
1. 城市航拍开场
2. 河流桥梁
3. 街道生活
4. 美食与人文
5. 文旅活动
6. 夜景收束

### 第四步：Codex + HyperFrames 合成
- 把6段视频按时间线拼接
- 自动填充字幕

### 第五步：剪映完成声音设计
- 配音 + 背景音乐 + 环境音
- **环境音很关键：** 清晨加蝉鸣鸟叫、河边加水流声、街道加汽车引擎、夜景加城市环境音

## 关键工具清单
| 工具 | 用途 | 成本 |
|:----|:-----|:-----|
| ChatGPT | 脚本、分镜、提示词 | 免费/付费 |
| GPT Image | 分镜参考图 | 付费 |
| Seedance / 豆包 | 参考图→视频 | 有免费额度 |
| Codex + HyperFrames | 视频拼接+字幕 | 付费 |
| 剪映 | 配音、环境音 | 免费 |

## 核心方法论
- 60秒拆成6个10秒片段 → 质量可控
- 先规划再出图 → 再生成视频 → 再合成 → 再声音设计
- AI做技术活，人做审美和编排
