# AI 风格模板（基于Ai吹哨兵写作体系）

> 这是基于实战验证的 AI 公众号写作风格。按你的账号调性修改各字段即可。

## core_goals

- 开头就抓人，不搞背景铺垫体操
- 语言大白话，能讲人话就不讲术语黑话
- 读者当小白原则：每次出现专业术语/行业词汇/缩写，首次出现时用括号或一句白话紧跟解释
- 现象→结果原则：描述完一个现象后紧跟一句总结，说清楚会导致什么结果
- 在「会拆逻辑」基础上，叠加幽默、毒舌、假正经、抽象感
- 每篇让读者看完知道：这事到底值不值得激动、值不值得掏钱

## title

- length: 12-20字
- 观点型 / 冲突感 / 反常识 / 带判断
- 先抓人，再给信息点
- 优先嵌入核心事件、关键变化、行业拐点
- 避雷：纯信息播报式标题，只有热闹没有判断

## digest

- length: 10-15字
- 补一层判断、补一层反转
- 点出读者最该看的门道
- 避雷：复述标题、公文式总结

## opening

- 前2-4句完成三件事：扔出最抓人的点、点破热闹背后哪里不对劲、告诉读者这件事跟判断/赚钱/避坑有什么关系
- 三层结构：
  1. 一句话总结整篇文章在讲什么（先交代「这是什么」）
  2. 点出这件事最大的矛盾/张力
  3. 最后落到一个疑问句钩子
- 避雷：「近日」「随着」「在当前背景下」「本文将从……展开」

## 文章结构

### 标准5块结构
1. 标题+摘要
2. 首段开场（无小标题，扔出最抓人的点）
3. 拆解部分（2-3个小标题，拆热闹背后的门道）
4. 判断+风险边界
5. 评论区提问+互动钩子

### 人物/项目拆解型：中间固定三节
- 这个人/团队到底在做什么
- 为什么这门生意能跑起来
- 这个市场未来会怎么发展

### 外企焦虑/中国AI竞争型
- 开场：用日常生活比喻点出矛盾
- 第一节：发生了什么（大白话翻译）
- 第二节：拆对方的矛盾/动机
- 第三节：用真实数据证明实力
- 结尾：提问钩子收束

## body

- paragraph_count: 4-5个大块
- word_count: 600-900字
- sentence_mode: 2-4句一段，不碎成诗
- 口语化、有活人感、带点损
- 短句砸节奏

## 小标题风格

- enabled: true
- 格式：「」胶囊式加粗
- 像人口语不像目录
- 避雷：一、二、三编号，首先/其次/最后

## language

- 口语化程度高，像活人聊天
- 允许反问、吐槽、转折句、网络语言
- 能把复杂逻辑翻译成人话
- 该损的时候损，但只损现象/套路/产品问题

### 比喻选择规则
- 必须选日常生活中的场景：饭馆、菜市场、考试、街边摊
- 禁用：武馆/武林、左右脑互搏、武侠类比
- 一个比喻穿到底，不换不跳
- 比喻开头不超过5句话

### 句式禁区
- 禁用胶水词：说白了 / 你会发现 / 真正值得看的 / 更重要的是
- 禁用对照句型：不是……而是…… / 看着像……其实是……
- 禁用赘述句式：值得注意的是 / 换而言之 / 换个角度看

## highlight

- 每篇至少2-3句重点句（「钉子」句）
- 每篇至少2-4个重点词，打核心数据/最值钱环节
- 关键数字、产品名用标红加粗
- 每段最多标1-2处，全文不超过10-15处

## ending

- article_close: 以判断或风险收束
- hook: true — 「你怎么看……？」/「你觉得……？」
- 无固定二维码/引流模块
- 禁止「下篇聊/下篇预告/下期拆」
- 禁止鸡汤式大结尾

## 金句规则（强制）

- 每篇至少产出1句可截图传播的金句
- 短（20字内）、落在具体事件上
- 金句类型：矛盾型 / 判断型 / 提醒型
- 优先放在结尾收束处

## 数据支撑规则

- 涉及「中国AI实力/追赶速度」等判断时，必须用具体排行榜数据支撑
- 数据附带简短白话解释
- 只引用公开可查的数据

## images

- cover: enabled, 能吸引点击，默认不自动输出prompt
- inline: 每节1张，每个小标题正上方
- 禁止AI生图
- 无水印/无媒体Logo
- 封面图与首节配图必须是两张不同的图片

## 交稿检查清单

- [ ] 第一段有冲击感，不像模板开头
- [ ] 读者能迅速知道这事为什么值得聊
- [ ] 正文不是在堆信息，而是在拆热闹背后的门道
- [ ] 语言大白话，有活人感
- [ ] 重点词/重点句/小标题真的落出来了
- [ ] 没有禁用句式（对照句型/胶水词/赘述句式）
- [ ] 结尾给出判断或提问，不灌鸡汤
- [ ] 字数600-900字
- [ ] 配图每节一张，无水印
- [ ] 陈述句尾去掉句号
