# 微信公众号发布合规规则（2026-05-15 实战经验）

## 封号风险警示

**非真人自动化创作检测：** 微信后台会对以下特征判定"非真人自动化创作"并封号：
- 多篇文章使用同一套 CSS 类名/颜色值/段落间距（HTML 指纹）
- 段落节奏过于固定（每篇都是1-2句一段、每段间距完全一致）
- 文章结构模板化严重

**规避策略：**
- 忌直接复制完整 HTML 粘贴到公众号编辑器（保留完整 HTML 指纹）
- 建议输出纯文本版，用户手动排版（加粗/标红/分段），时间多花3-5分钟
- 或每篇使用不同的 CSS 类名、不同的颜色值但保持视觉一致

## 必选固定模块

**风险提示（所有涉及加密/投资/代币的文章强制）：**
每条 style 的固定提示必须出现在正文中。

以链小智为例：
> ChainThink温馨提示：加密货币风险高，远离投机，保护个人财产

位置：封面图下方、正文首段上方。居中、灰色、字号14px。

## 标题/摘要合规

- 不带"收割""实锤""暴富"等易被识别的词
- 不带感叹号（避免营销感）
- 结论中性：如"预期升温"替代"收割流量"
- 字数严守 style 要求（含英文按3字母=1汉字折算）

## 图片合规

- 所有图片必须下载到本地，不能在公众号编辑器里直接引用外链
- 图片来源优先选：原文页面提取 → vxtwitter 推文配图 → Unsplash 免费图库
- 不得使用 AI 生成图片
- 图片内不得有来源媒体 logo/水印

## 审核严格模式（2026-05-18 实战）

当用户明确说"审核严格"或要求"优化得好一点"时，在已有合规规则基础上，执行以下额外策略：

### 收益承诺红线升级
- 源素材中的高额收益数字（如"月入$10万"、"日入1000"）**不能直接引用**。改为以下方式之一：
  - 用"听听就好"框架主动打脸：原文提到的高额数字 → "那个数字听听就好，能稳定月入几千算跑通"
  - 降维表述：如"说的不是一个普通人的收入，是批量操盘的上限"
- 任何收入相关表述必须带**条件前缀**："有人能……"、"取决于……"、"天花板是……"
- 禁止任何形式的"XX天赚XX"直接句式，即使源素材这么写也不照搬

### 风险占比提升
- 在文章最后1/3位置必须有一个**独立的风险/天花板小节**（不是一句话带过）
- 该节至少包含2-3个具体风险点（平台政策、同质化、运营门槛等），每个风险点用具体场景说明
- 不允许用通用模板风险话术（如"投资有风险入市需谨慎"），要针对本文讨论的具体路径说风险

### 免责声明前置
- 在封面图下方、正文首段上方固定加一行小字免责声明，灰色14px居中
- 内容模板：「免责声明：以下内容仅为信息分享，不构成任何投资建议或收益承诺。具体操作结果因人而异，请理性判断」
- 非加密/B站文章可酌情简化，但涉及赚钱/变现/收益话题时必须保留

### 实战案例（2026-05-18，Ai掘金仔 — Swaptok搬运话题）
源素材推文宣称"月营收做到十万美金"，处理方式：
1. 全文不引用$100k数字作为事实
2. 在风险节写道：「月入十万美金的说法听听就好，那种话不是说给你听的」
3. 最后一句落点在运营能力而非收益：「会做内容、会养号、会找客户，比会点'生成'按钮重要一百倍」
4. 前置免责声明 + 独立风险节（平台政策/同质化/运营门槛三个具体风险点）
5. 用户无任何修改要求即通过 — 策略有效

## 结尾合规

- 必须用"你怎么看/你觉得……"形式提问钩子
- 禁止"下篇聊/下篇预告/下期拆"
- 社交媒体引流语要克制，不要出现"扫码进群""加群"等（可能触发引流违规）
- 外部链接（如 chainthink.cn）谨慎使用，建议直接去掉或用"关注公众号"替代
