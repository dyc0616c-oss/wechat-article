# style-money（Ai掘金仔）

## 账号定位
- AI变现指南型公众号
- 主写：AI副业、AI赚钱方法、AI工具变现、低成本创业方向、兼职/全职AI搞钱路径
- 不是产品测评号，不是行业分析号，不是投资建议号
- 更像一个天天研究AI怎么帮普通人赚钱的人，一边拆路径，一边给判断，一边提醒别踩坑

## 核心写作目标
- 每篇文章必须回答一个问题：这件事普通人能不能复制、能赚多少、门槛在哪
- 开头直击场景，不铺垫背景
- 语言大白话，像朋友在跟你聊项目
- 每篇至少给一条可执行的动作建议
- 每个赚钱路径都要给出具体的数字、门槛、天花板判断

## 标题生成规则

### 主标题要求
- 风格：直接、利益驱动、数字优先
- 结构：数字/动作/场景 + 结果判断
- 长度：12-22字
- 常用形式：
  - 「AI改简历一周赚1260」
  - 「AI 一小时快速出片，四成基础剪辑岗面临替代」
  - 「网盘拉新，动动手就能日入100？」
  - 「AI 女友陪聊月入 20 万」
- 数字必须前置：把最有冲击力的数字放最前面
- 可以带问号制造悬念，但不能纯标题党
- 禁止：
  - 纯信息播报式标题
  - 行业黑话堆砌
  - 只有热闹没有利益暗示

### 摘要
- 长度：10-18字
- 作用：补关键信息或补一句判断，不重复标题
- 常用写法：
  - 「动动手打打字就能月入过万」
  - 「一句话去水印，友商集体破防」
  - 「全是虚拟人设剧本，背后都是精准流量收割」
  - 「Codex出图+HyperFrames出片，已获流1000万以上」
  - 「AI资料分享竟然有这么大的市场」

## 首段规则

### 固定写法（强制）
1. 第一句话直接扔场景/矛盾/问题，不铺垫
2. 第二句话点明「这事跟读者有什么关系」
3. 第三句自然过渡到拆解

### 常用开头方向
- **场景代入式**：想象一个具体的日常场景→引出问题→给方案
  - 例：「想象一下你刚拍完一段视频，正打算往上贴字幕，画面里有个老头乱入了……现在呢？不需要了」
- **结果先行式**：先扔赚钱结果→再倒推怎么做到的
  - 例：「有人用AI帮人改简历，第一周接了1260」
- **痛点直击式**：直击一个真痛点→给解法
  - 例：「以前做视频，找素材、学剪辑、配音乐，一套下来投入成本极高。现在有人用Codex+HyperFrames，1小时做完一条宣传片」

### 禁止
- 近日……随着……在当前背景下……
- 一大段背景铺垫才进入主题
- 先讲行业趋势再讲具体事件

## 正文结构规则

### 默认三段骨架（强制）
当文章是「AI赚钱方法拆解型」时，中间默认固定为：

1. **这件事怎么操作的**（操作步骤/工具/流程）
2. **为什么真能跑起来**（需求分析/市场判断/案例验证）
3. **天花板和风险在哪**（能做多大/不能做多大/什么情况会翻车）

执行要求：
- 每节必须有具体案例或数据支撑
- 少写抽象判断，多写「某个人/某个号/某笔单子」的具体情况
- 能用案例替代概括句，就不要空讲道理
- 每节开头优先直接给出本节结论，再展开

### 默认正文长度
- 600-900字
- 1-2句一段
- 重点句、数字句、判断句可单独成段

### 常用结构模板

#### 单一赚钱路径拆解型
1. **开头：扔案例/场景**
2. **怎么操作：工具+步骤+关键技巧**
3. **为什么能跑：需求大/门槛低/时机好**
4. **天花板与风险：能赚多少/不能赚多少/谁不适合**
5. **结尾：怎么开始+互动提问**

> AI视频制作类赚钱路径参考 `references/ai-city-promo-workflow.md`（五步工作流：ChatGPT策划→GPT Image分镜→豆包/Seedance出视频→Codex+HyperFrames合成→剪映配音）

#### 多路径对比盘点型
1. 开头：赚钱焦虑+AI机会
2. 路径A：操作+数据+判断
3. 路径B：操作+数据+判断
4. 路径C：操作+数据+判断
5. 横向对比：门槛/天花板/适合人群
6. 结尾：哪个最值得试+提问钩子

#### 一人AI成功故事拆解型（2026-05-22 新增）
适用场景：素材是一个「具体的人用AI做了一件事并赚到钱」的成功案例——如某人用Claude Code建SaaS月入$6327、一人做出爆款AI工具等。

核心差异：这不是步骤型教程（读者无法完全复制对方的操作），而是**模型拆解**——把成功路径抽象为可复制的模式/闭环/方法。

结构骨架（固定）：
1. **开头结果先行**：先扔最核心的赚钱数字（月入$XX、增长XX%），一句话让读者知道"这事有多赚"
2. **「产品/项目长什么样」**：拆解对方做了什么产品、包含哪些功能模块、怎么收钱（订阅/按次/包月）——聚焦产品结构，不写技术细节
3. **「钱是怎么赚出来的」**：拆解3个关键动作——开发怎么干的/内容怎么分发的/用户怎么转化的。提炼成闭环句式（如：做产品→发内容→吸用户→收订阅→迭代）
4. **「这条路能不能跟」**：给出真实的复制门槛（不是技术门槛，是综合能力门槛），区分"谁适合"和"谁不适合"
5. 结尾：一句收束判断（这条路未来会怎么走）+ 互动提问钩子

写作要点：
- 不写技术实现细节（不是键盘怎么敲）
- 不写公司背景废话
- 聚焦在**操作链路模型**上——读者学的是"怎么做AI独立开发者"的思维框架，不是学写某行代码
- 每节开头直接给出本节结论，再展开案例支撑
- 参照参考示例：`references/style-money-case-bridge-mind.md`

与单一赚钱路径拆解型的区分：
| 维度 | 单一赚钱路径拆解型 | 一人AI成功故事拆解型 |
|------|-------------------|---------------------|
| 素材类型 | 副业方法/工具用法（可复制步骤） | 真人案例/创业故事（可复制模式） |
| 核心问题 | "怎么操作" | "他做对了什么" |
| 读者拿走 | 操作清单 | 思维模型/创业方法 |
| 案例位置 | 嵌入操作步骤中 | 贯穿全文为主体 |

## 语言风格规则

### 核心风格
- 像一个懂AI赚钱路子的人在跟你聊天，不像分析师在做报告
- 多短句，口语化
- 多用「你」拉近距离
- 多用具体数字替代模糊表述
- 可以吐槽，但吐槽要放在「这路子不太靠谱」的判断场景里，不要为了吐槽而吐槽

### 常见口语方向
- 「动动手打打字」
- 「拆解下来发现是个人都能做」
- 「这数据是实实在在有人跑出来的」
- 「核心能力就两样：……」
- 「这事儿换算成时薪并不夸张」
- 「你说得没错，就是靠这个赚钱的」
- 「平台已经搭好，拼的就是执行力」
- 「说实话这不是什么快速致富的路子」

### 禁止
- 书面汇报腔
- 研究报告腔
- 空洞鸡汤：「相信自己/努力就有回报」
- 过度夸张：「一夜暴富/月入百万」
- 过度网感油腻：每段都用热梗

## 反AI写作规则

### 1. 禁用过渡关联词
- 值得注意的是、不容忽视的是、从某种意义上说
- 这意味着、这说明、这充分说明
- 本质上而言、其核心在于
- 首先/其次/最后（作为段落引导时禁用）

### 2. 禁用AI对照句型
- 不是……而是……
- 表面……实际……
- 看似……实则……
- 你以为……其实……
- 这事最……的地方

### 3. 禁用AI化词语
- 迅速、立即、瞬间、立马、显著、大幅、快速
- 完美地、出色地、成功地、有效地、极大地
- 实际上、事实上、根本上

### 4. 禁用素材痕迹
- 原文中提到的、原贴里说、素材显示
- 我看到有人说、某篇文章标题
- 有媒体称、据报道、据称

### 5. 禁用项目符号列表
- 正文默认不用 `-` `•` 编号列表
- 用自然段落或短句并列替代

### 排版规则（实战修正 v2）
- 陈述句段尾默认不加句号
- 问号保留，感叹号适当使用
- `「」`胶囊式小标题，白字红底胶囊，段前段后间距24px
- **段落合并规则（用户2026-05-20纠正）**：每段最多2句，2句饱满不碎、1句自然不单薄。相关的一组句子合并到一个段落，不要把每个短句都单独成段（否则像诗），也不要把3句以上塞进一段（否则像论文）。每个段落视觉长度2-4行
- 禁止在段落之间使用`─────`等分隔线
- 结尾使用统一的 `.end-hook` CSS class，禁止内联样式
- 全文CSS保持统一模板，禁止混用内联style
- 高频分段但不碎片化，适合公众号扫读
- 重点数字加粗突出

## 结尾规则

### 固定结构（强制）
1. 一句收束判断：对这条赚钱路径的总体评价
2. 评论区互动钩子：以「你怎么看/你觉得……」提问
3. 群引流（可选）：Ai掘金仔保留固定群引流口播

### 禁止
- 「下篇聊/下篇预告/下期拆」
- 只有判断没有提问
- 空洞鸡汤收尾

## 配图规则
- 每个小标题上方配一张直接相关的图片
- 封面图1张 + 每节1张图
- 配图走「中间地带」：不太写实（不用纯产品图），不太抽象（读者看不懂跟内容的关系）
- 优先找真实场景图：人在操作AI、项目界面、案例截图等
- 不在正文中用「🖼️【配图:...】」占位符
- 不使用AI生成图片

### 素材处理规则
- 收到写作任务时，必须打开并阅读所有素材链接
- 必须搜索至少3-5篇补充素材，不得仅依赖单一链接
- 信息无法确认时标注「待确认」
- 不做绝对化收益承诺
- 不编造数据、来源、案例
- **禁止以「某推主/某博主 发了条推文/帖子说」开头**：正文默认以账号自身为源头，直接以事件/案例切入，不写成对第三方帖子的回应

## 与style-c的区别
| 维度 | style-c（Ai吹哨兵） | style-money（Ai掘金仔） |
|------|-------------------|----------------------|
| 核心定位 | 吹哨、避坑、拆穿 | 变现指南、教赚钱 |
| 语言温度 | 毒舌、吐槽、抽象幽默 | 直接、务实、朋友聊天 |
| 正文重点 | 拆热闹背后的门道 | 拆可复制的赚钱路径 |
| 案例写法 | 写为什么危险/忽悠 | 写怎么操作/赚多少 |
| 情绪基调 | 警惕、判断、扎心 | 务实、落地、可执行 |
| 结尾 | 评论区提问+下篇预告 | 评论互动+群引流 |
| **产出模式** | 单版本 | **双版本**（原风格A + 正经版B） |
