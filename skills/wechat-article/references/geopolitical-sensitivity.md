# 地缘政治敏感内容改写规则

涉及中美、AI 博弈、科技制裁等题材时，必须遵守以下改写规则。

## 核心原则

**主线从"中国被怎样"改成"行业发生了什么"。**

## 强制改写规则

### 1. 标题规则
- ❌ 禁止"拒中国门外""中国被排除""中国没有席位"等被动/弱者视角
- ✅ 用技术能力、行业冲击、安全格局变化等中性/积极表述
- ✅ 如必须提中国，用"国产替代""安全赛道加速"等正向措辞

### 2. 开篇规则
- ❌ 禁止以"中国请求 X → 被拒绝 → 丢脸"视角驱动
- ✅ 以事件本身的技术/行业影响力开篇
  - 正确：先讲这个产品/事件牛在哪，再补一句地缘背景
  - 错误：第一段就讲中国如何如何被拒

### 3. 叙事框架
- ❌ 中国相关事实作为主线驱动
- ✅ 中国相关事实作为背景信息嵌入，不主导全文情绪
- 核心叙事轴：技术能力 → 行业影响 → 安全格局 → 国产进展

### 4. 外媒负面引用
- ❌ 外媒对中国的直接批评/负面定性整句删除
- ✅ 只保留客观事实性信息（数据、事件经过）
- 原则：能说明"发生了什么"，不保留"别人怎么评价中国"

### 5. 结尾规则
- ❌ 禁止"中国该怎么办/中国该选哪条路"式被动收尾
- ✅ 必须转向正面收束：国产替代进展、市场增长前景、追赶态势
- ✅ 结尾提问落在行业进度上（"国内厂商多久追上"而非"中国能拿到入场券吗"）

## 实战改写对照

| 原文（有风险） | 改后（安全） |
|-------------|-----------|
| Mythos拒中国门外，白宫拉响AI安全警报 | Mythos挖出27年前的漏洞，AI安全赛道被重新洗牌 |
| 中国在这张安全升级的桌子上，没有席位 | 国内AI安全赛道既有现实需求，也有明确的增长空间 |
| 拜登时期中国在安全对话中收集美方信息，而非认真讨论 | 整句删除 |
| 白宫官员认定这是中国在AI领域持续施压的信号 | 整句删除 |
| Anthropic把中国列为"对抗性国家" | Anthropic将中国置于严格限制名单 |

## 自检清单

发稿前逐项确认：
- [ ] 标题有没有"被拒/被排除/丢脸"等弱者视角？
- [ ] 开篇第一段是不是首先讲技术能力，而非讲中国处境？
- [ ] 有没有直接引用外媒对中国的负面评价？
- [ ] 结尾情绪是正向收束还是被动叹息？
- [ ] 中国相关事实是背景嵌入还是主线驱动？
