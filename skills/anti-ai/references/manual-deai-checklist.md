# 手动降AI实操清单（2026-05-30 实战验证）

> 当用户无付费工具、或明确要求「你先自己降」时，按此清单执行。已验证可行。

## 前置检查

动手前先确认两件事：

1. **目标账号是哪个style？** — 不同style的禁用词不同。如style-c禁用「说白了」「你会发现」等，但style-thinks-ai不禁用这些。口语化标记选错=踩雷
2. **原文HTML格式是否已存档？** — 备份原文，万一改坏了能恢复

## 执行顺序（按效果递减）

### 第一刀：删AI过渡句（效果最大，2分钟）

全文扫描以下结构，直接删掉或替换为事实句：

| 原文 | 改为 |
|:----|:----|
| 有意思的是/值得注意的是/不相上下的是 | 直接删掉，后面接续事实句 |
| 明显是/显然/本质上/从根本上说 | 删掉或改为「摆明了」「说白了就是」 |
| 但/然而/不过（句首转折） | 改为「可」「其实」「讲真」「不过嘛」 |
| 这意味着/这说明/这充分说明了 | 删掉，直接写结论 |
| 由…等共同/分别/包括 | 直接列名单，「由…等」结构去掉 |

### 第二刀：换高频AI词（5分钟）

全文替换以下高频词（注意：step 9替换表里有更多，但以下是最容易暴露的）：

| 高频AI词 | 替换为 |
|:---------|:-------|
| 如果 | 要是/假如/真要 |
| 但是/然而 | 可/不过/其实/然而嘛 |
| 超过/领先 | 超了/甩在/压过/盖过 |
| 本质上/实际上/事实上 | 删掉或改用「说白了」「讲真」 |
| 明显是/显然是 | 摆明了/明摆着 |
| 这是一个/这是一种 | 删掉「一个/一种」，直接陈述 |
| 由此/因此/故而 | 这不就/所以嘛/于是 |
| 进行/开展 | 做/搞/干 |
| 进一步提高/进一步加强 | 更…了/又往上顶了一把 |

**纪律：**
- 每1000字至少替换5-8处
- 同一替换全文不超过2次
- 优先替换每段开头第一句的高频词

### 第三刀：加口语标记（3分钟）

选style-safe的口语标记注入，每200-300字1处：

**style-thinks-ai 安全标记：**
- 说真的、说到这儿、你想想、你发现没有
- 说白了、那么问题来了（style-thinks-ai不禁用这些）

**style-c（Ai吹哨兵）安全标记（避开禁用词）：**
- ✅ 说真的、你想想、然后呢
- ✅ 好家伙、绷不住了、我勒个
- ❌ 说白了（style-c禁用胶水词）
- ❌ 你会发现（style-c禁用）
- ❌ 更重要的是（style-c禁用）
- ❌ 这说明什么（style-c禁用）

**style-money（Ai掘金仔）安全标记：**
- 说真的、你想想、你琢磨琢磨、说白了
- 好家伙、这账算得明明白白

### 第四刀：调句子节奏（5分钟）

四类调整：

1. **拆长句** — 超30字的长句，在逻辑断点处拆成两句。拆完后阅读节奏明显变快
2. **合碎段** — 连续2-3个短单句（均<15字）且语义连贯的，合并成一句用逗号分隔。避免「写得像诗」
3. **改语序** — 主谓宾调换位置，把后置修饰语前置。如「弄丢了自己的身份」→「把自己给弄丢了」
4. **加口语连接词** — 在推进处加「然后」「这不」「这下」「好家伙」，替代「因此」「于是」「接着」

### 第五刀：改标点+语气词（2分钟）

| 原文 | 改为 |
|:----|:----|
| 这是什么水平？ | 啥水平？ |
| 这是……的结果 | 这就是……搞的/闹的 |
| 这说明了…… | 这俩放一起一看—— |
| XX， YY， ZZ连续逗号 | 部分改为句号，制造短句节奏感 |
| 句尾没语气 | 加「嘛」「吧」「呢」「了」点缀 |
| 排比句 | 打断一个，改为口语短句 |
| 很/非常/极其 | 删掉或用更具体的表达替换（「非常快」→「嗖嗖的」） |

### 第六刀：替换书面结构词（3分钟）

| 原文 | 改为 |
|:----|:----|
| 还差一步/只差一步 | 就差一脚/就差一口气 |
| 还差一点 | 还差这么一哆嗦 |
| 已经很好了 | 够可以了 |
| 价格也没变 | 价格嘛，还是老样子 |
| 大家都习惯了 | 大家都懂/看麻了 |
| 本质上就是 | 其实就是/说白了就是 |

## 格式保护自检（强制）

每次改完后，对照原始HTML逐项确认：

- [ ] 胶囊小标题 `<div class="titlestyle">` 还在吗？数量没变吗？
- [ ] 每节配图 `<div class="img-wrap">` 还在对应小标题正上方吗？
- [ ] 封面图位置移动了吗？
- [ ] 节划分（每节的内容归属）被打乱了吗？
- [ ] HTML文件行数变化太大（超过原始±20行）→ 可能格式被破坏了

**如果任何一项不通过，从备份恢复格式，重新做语言替换。**

## 验证方法

1. 保存HTML后，把正文纯文本复制到朱雀检测：https://matrix.tencent.com/ai-detect/ai_gen
2. 人工>30% → 合格，可交付
3. 人工<30% → 回到第一刀重新走一遍，更狠地改
4. 0% → 停，问用户要不要换群聊体/午夜好友体（不要自作主张）

## 2026-05-30实战参考

### 链小智（style-thinks-ai）实际改动
- 加：说真的×1、说到这儿×1、你想想×1、你发现没有×1
- 换：核心逻辑→意思、如果→要是、补了一句→补了句、这是什么水平→啥水平、换一个→换个
- 合并：两处过碎短段（「路短了延迟就低功耗也更小」合并到前段）
- 加反问：「他能在台北的晚宴上说……吗？不能。」

### Ai吹哨兵（style-c）实际改动
- 加：说真的×1、摆明了是×1、那群人×1、怕是要被偷家×1
- 换：可能真→怕是要、本质上→删掉、超过→超了、但→不过、还差一步→就差一脚
- 删：有意思的是→删掉、由…等共同→直接列
- 合：「但跑分嘛，大家都习惯了」→「不过跑分嘛，大家都懂」
- 调语序：「先弄丢了自己的身份」→「先把自己给弄丢了」
- 拆句：「主要更新就两样：一个是……随便调；另一个是……干活」→拆成两句

## 2026-06-02实战教训：Ai掘金仔手动降AI翻车记录

**事件：** 对Ai掘金仔版本A（style-money、开源闲鱼管家）执行手动降AI

**改了什么：**
- 原文已经很口语化（手就开始怀疑人生了、系统还在干活、保命操作、齐活）
- 降AI改了：专门治这个毛病→专门治这个、简单说→说白了你、不用每次都手打→不用回回都手打、系统还在干活→机器还在接班、搞定→齐活、最合适→最对口、多账号运营者也合适→多号党也值得试试、最适合谁→最对口的还是

**用户评价：** 「额，还是用原来的吧，这个版本还不如原来的」

**教训总结：**
1. Ai掘金仔版本A本身已经足够口语化（写的时候就是按大白话写的），手动降AI反而破坏了原有的"朋友聊天"自然感
2. 替换词太刻意（"机器还在接班"不如"系统还在干活"自然）
3. **Ai掘金仔的写作风格本身就是口语化的**，降AI空间很小，强行替换反而更难读
4. 下次Ai掘金仔要降AI，优先推荐用户上付费工具，不主动手动改
