# WeChat Article — 公众号内容自动化系统

> 实战验证，周产25+篇优质公众号文章（数据来自原始作者）
> 一个能学会你文风、按你风格自动写稿的 AI 写作系统

---

## 一句话

**给 5 篇你的历史文章 → 系统学会你的风格 → 之后给个选题就能按你的风格出稿**

---

## 快速上手（3 分钟）

### 第 1 步：让系统学你的风格

挑 **5-10 篇**你写过觉得最像自己的公众号文章，把链接发过来：

> 「帮我学一下这个公众号的风格，这是 5 篇文章链接：[链接1][链接2]…… 公众号名叫 XX」

系统会从 **10 个维度**分析你的文章（标题风格、段落节奏、口语化程度、结尾方式……），生成一个专属 `style-你的号.md` 文件。

### 第 2 步：日常写稿

> 「用 XX 号写一篇关于 XXX 的文章，素材：https://x.com/xxx/xxx」

系统自动完成：
1. **读取素材** — X 链接/网页/URL 一键提取
2. **搜索补充** — 搜 3-5 篇相关报道验证+补充角度
3. **按你的风格写稿** — 标题、摘要、正文全部按 style 规则输出
4. **事实核查** — 逐句验证文中每个数字和声称
5. **配图** — 从源素材/网络下载配图
6. **出稿** — 保存 HTML 到桌面

### 第 3 步：降AI（可选）

写完后系统会问你要不要降AI。你有两个选择：

| 方案 | 说明 |
|:----|:-----|
| **付费工具** | 用市面上的降AI工具处理（推荐，最高可达41%人工率） |
| **手动降AI** | 系统做语言层轻量替换（换高频词、调语气、拆长句） |

### 第 4 步：发布

HTML 文件路径：`~/Desktop/公众号文稿/月.日/公众号名/标题.html`
粘贴到公众号编辑器 → 过一遍 → 发布

## 核心功能

| 功能 | 说明 | 怎么触发 |
|:----|:-----|:--------|
| 风格学习 | 从5-10篇历史文章提炼可执行风格规则 | 「学一下这个号的风格」 |
| 单篇写作 | 给素材→按风格出稿 | 「用XX号写一篇关于XXX的」 |
| 改写润色 | 给文章→按目标风格重写 | 「把这篇文章改写成XX号的风格」 |
| 事实核查 | 逐句验证所有数字和声称 | 自动执行 |
| 降AI处理 | 检测→降AI→过朱雀 | 写完后自动询问 |
| 多账号并行 | 同一主题出5个号版本 | 「按这5个号各写一篇」 |
| 自动存草稿 | 通过微信API保存到公众号草稿箱 | 需要配微信开发者平台 |

## 写作规则速览（所有号通用）

| 规则 | 具体 |
|:----|:-----|
| **不编造** | 找不到真实案例就删段，不虚构 |
| **不自创数据** | 所有数字必须有官方出处，券商预测必须标注 |
| **每段1-2句** | 手机上扫读舒服，不把3句以上塞进一段 |
| **不说黑话** | GMV→「多卖了几成」，MAU→「日活多少」 |
| **标题有钩子** | 必须有信息增量（数据/人名/冲突/反常识） |
| **陈述句尾无句号** | 感叹和问号保留 |
| **关键词标红** | 数据/产品名/核心判断用红色加粗 |
| **小标题用「」** | 口语化胶囊式，不用编号目录 |
| **结尾有互动** | 「你怎么看，……？」+ 可截图传播的金句 |

## 前置要求

### 写稿（wechat-article）
- Hermes Agent（运行这套 skill 的平台）
- 公众号历史文章链接（做风格学习）
- 可选：素材源（X/Twitter链接、文章URL）

### 自动存稿（wechat-draft）
- 微信开发者平台 AppID
- 微信开发者平台 AppSecret
- 出口 IP 加入 API 白名单
- `config.json` 配置
