# WeChat Article — 公众号内容自动化系统

> 实战验证，周产25+篇优质公众号文章
> 一个能学会你文风、按你风格自动写稿的 AI 写作系统

## 一句话总结

只要你提供：
- **5-10 篇用于学习风格的公众号素材**
- **Hermes Agent**（运行这套 skill 的平台）
- 可选：**微信开发者平台的 AppID / AppSecret**（如需自动存稿）

这套东西就可以帮你实现：
- 按你的公众号风格自动写稿
- 自动把文章保存到公众号草稿箱

---

## 这个仓库适合谁？

适合这些人：
- 想做公众号内容自动化
- 有多个公众号账号，想让每个号风格不一样
- 想把「写稿」和「存稿」拆开做
- 想把自己的公众号风格训练成可复用模板
- 想让 AI 写完后直接进入公众号草稿箱

---

## 仓库里有什么？

### skills/wechat-article（写稿）
这是主技能，负责：
- 写公众号文章
- 二创改写
- 生成标题、摘要、正文
- 按不同账号风格生成内容
- 输出适合公众号排版的版本

**不负责：** 不处理微信公众号开发者平台 API，不直接写进公众号草稿箱。

### skills/wechat-draft（存稿）
负责：
- 接微信公众号开发者平台 API
- 获取/刷新 access_token
- 上传封面图
- 自动保存文章到公众号草稿箱

**不负责：** 不负责文章风格写作本身，不负责训练公众号文风。

### skills/anti-ai（降AI）
负责：
- 8步降AI工作流
- 高频AI词替换
- 朱雀检测对接
- 群聊体/午夜好友等核方案

## 快速上手

### 第1步：让系统学你的风格

挑 **5-10 篇**你写过觉得最像自己的公众号文章，把链接发过来：

> 「帮我学一下这个公众号的风格，这是5篇文章链接：[链接1][链接2]…… 公众号名叫 XX」

系统会从 **10个维度**分析你的文章（标题风格、段落节奏、口语化程度、结尾方式……），自动生成一个专属 style 文件。

> 不想从零写 style？仓库里已经提供两个现成模板：
> - `style-web3-template.md` — 基于链智库写作体系，适合Web3/加密行业号
> - `style-ai-template.md` — 基于Ai吹哨兵写作体系，适合AI行业号
>
> 直接拿去填空修改即可。

### 第2步：日常写稿

> 「用 主号 写一篇关于 XXX 的文章，素材：https://x.com/xxx/xxx」

系统自动完成：
1. **读取素材** — X链接/网页/URL一键提取
2. **搜索补充** — 搜3-5篇相关报道验证+补充角度
3. **按你的风格写稿** — 标题、摘要、正文全部按style规则输出
4. **事实核查** — 逐句验证文中每个数字和声称
5. **配图** — 从源素材/网络下载配图
6. **出稿** — 保存HTML到桌面

### 第3步：降AI（可选）

写完后系统会问你要不要降AI。两个选择：
| 方案 | 说明 |
|:----|:-----|
| 付费工具 | 用市面上的降AI工具处理（推荐，可达41%人工率） |
| 手动降AI | 系统做语言层轻量替换（换高频词、调语气） |

### 第4步：发布

HTML文件路径：`~/Desktop/公众号文稿/月.日/公众号名/标题.html`
粘贴到公众号编辑器 → 过一遍 → 发

## style 是什么？

这个仓库里有一个很重要的设计：

> **一个公众号账号 = 一套风格规则（style）**

比如：
- 公众号A = 犀利吐槽风
- 公众号B = 专业分析风
- 公众号C = 聊天式口语风

这样以后你不用每次都跟AI解释这个号该什么风格，只要提前写好style文件，后面直接说：
> 「按 主号 发」
> 「按 AI号 风格改」

系统就会自动读取对应的 style 文件。

### 怎么做自己的 style？

**方法A：自动学习**
给系统 5-10 篇你的文章链接，自动分析生成。

**方法B：手动填空**
复制 `style-web3-template.md` 或 `style-ai-template.md`，改成 `style-你的号.md`，按注释填上你的账号信息和写作规则。

然后把你的账号注册到 `account-style-map.json`：
```json
{
  "accounts": {
    "我的公众号": "style-我的号.md"
  }
}
```

## 我要准备什么？

### 只想写稿（wechat-article）
- Hermes Agent
- 公众号历史文章链接（做风格学习）
- 可选：素材源（X/Twitter链接、文章URL）

### 还想自动存稿（wechat-draft）
额外需要：
- **微信开发者平台 AppID**
- **微信开发者平台 AppSecret**
- **API IP 白名单**（把运行机器的出口IP加进去）

缺一不可，白名单没配好的最常见报错：
> `invalid ip not in whitelist`

## 常见注意事项

### 1. 只下载仓库 ≠ 立刻能自动写稿
需要 Hermes Agent 来加载这些 skill。

### 2. 不要把真实密钥传到公开仓库
不要提交：
- 真实 AppID / AppSecret
- 真实 access_token
- 你的公众号写作机密（style文件自己保留）

### 3. style 不是魔法，是「规则化你的习惯」
如果你的样稿本身风格不稳定，AI也很难稳定复刻。做style时尽量选最像自己、最稳定、最想长期复用的文章来提炼。

### 4. 想先跑个样品？
先跑写稿样品验证风格对不对 → 再跑自动存稿样品验证token和白名单。

## 一句话总结

如果你想做「公众号自动化」：
- `wechat-article` 帮你把文章**写出来**
- `wechat-draft` 帮你把文章**存进去**
- style 和映射表帮你把「不同账号的文风」**固定下来**
- `anti-ai` 帮你把AI痕迹**降下去**

先把风格跑顺，再把白名单配好，最后样品一跑，这套东西就真的能拿去用了。
